# 🌸 Cute Todo List App

A simple and responsive Todo List application built with React.js and Bootstrap.  
This project allows users to add, edit, save, and delete tasks with a clean pastel-themed UI.

## Features

- Add new tasks
- Edit existing tasks
- Save updated tasks
- Delete tasks
- Responsive design
- Soft pastel pink aesthetic UI

## Technologies Used

- React.js
- JavaScript
- Bootstrap
- CSS
